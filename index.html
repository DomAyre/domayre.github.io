  11. 2016Nov
    Project

    StressLess

    A smart stress ball built with magnets, Hall effect sensors, and Arduino.

    StressLess was a prototype smart stress ball I developed in a team during my Master's year, as part of an Interactive Devices unit.

    We put magnets and Hall effect sensors inside a regular foam stress ball and connected them to an Arduino board. The magnets let us measure how the ball was being squeezed.

    The prototype, sensing arrangement, and interaction.

    The idea was to connect a familiar stress ball to smart devices, responding with soothing lighting or music. Our proof of concept mapped squeezes to a colour on screen, which faded as the squeezing slowed.

    View StressLess on GitHub

  13. 2016Jun
    Project

    Rollout

    A battle arena blending physical robots with projected graphics.

    Rollout was my third-year group project. We were tasked with making a game that brought multiple technologies together in a compelling package.

    We combined Sphero robotic balls with an overhead tracking system built from off-the-shelf webcams, and a custom mirror system that reflected a projector image onto the floor. This let us overlay graphics on the physical robots.

    Physical robots, virtual weapons, and a projected arena.

    Players controlled their robots through a custom Android app and attacked each other using both virtual weapons and physical collisions.

  18. 2014
    Project

    Mynd

    A mind-mapping application built around a more engaging note-taking experience.

    I released Mynd in 2014 as a way to test my UX design skills and create a tool I wanted to use myself. While it didn't enjoy the same commercial success as Study Planner, I was particularly proud of its design and feel.

    I work best with structured notes, but many mind-mapping applications felt more suited to technical flowcharts. A graphic design seminar introduced me to the work of John Maeda, which inspired me to build my own.

    I used Win2D for high-performance custom graphics. Working with a new technology meant solving problems that didn't already have an answer on Stack Overflow.

    At the time of the original write-up, Mynd had fewer than 1,000 downloads and a five-star average rating.

  20. 2012

    Study Planner

    My first software project, which reached over 240,000 downloads.

    I created Study Planner in 2012 as my first experience of software development. What began as a project for myself and a way to learn to code became an app with over 240,000 downloads on Windows and Windows Phone.

    Windows Phone's distinctive interface had inspired me to download the developer tools. During my GCSE exam period, I worked through a 20-part web programming course for .NET developers, then set out to build a better way to manage timetables and homework.

    The application and its Windows Store reception.

    Study Planner was featured repeatedly in the Windows Store, both in education and on the store's front page. It was also included in the Creativ Bloq App Generator Competition's top ten. At its peak, it was the UK's number-one paid non-game app in the Windows Store.

    Alongside digital promotional material, I photographed an early version of the app.
